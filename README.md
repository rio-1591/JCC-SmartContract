# 🔥 Jesus Charity Coin (JCC)

**JCC** is a fully secured, decentralized ERC-20 token with built-in controlled burning functionality.  
It is designed for long-term value protection, inspired by the integrity of Bitcoin but aimed at charitable and ethical use cases.

---

## 🔐 Features

- ✅ Total supply: 21,000,000 JCC (fixed, like Bitcoin)
- 🔥 Owner-only burn function to destroy tokens irreversibly
- 🧠 Built using **Solidity** + **SafeMath** for overflow protection
- 📊 Transparent and trackable total burned tokens
- 🚫 No minting, no hidden functions, no central authority to print more

---

## 💡 Usage

- Deploy on Ethereum-compatible blockchain (mainnet/testnet)
- Use `transfer()` to send tokens  
- Use `burnToDead()` (owner only) to remove tokens from supply  
- Call `totalRareBurned()` to see how much has been burned
